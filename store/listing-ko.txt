Dev Toolkit은 개발하면서 자주 꺼내 쓰는 변환 도구를 팝업 하나에 모았습니다. 모든 도구가 브라우저 안에서 오프라인으로 동작합니다.

도구
- JSON: 2칸, 4칸, 탭 들여쓰기로 정리하고, 한 줄로 압축하고, 잘못된 JSON은 어디서 깨졌는지 보여 줍니다
- Base64: 한글을 포함한 모든 텍스트를 UTF-8로 인코딩하고 디코딩합니다. 표준과 URL 안전 형식을 모두 지원합니다
- JWT: 토큰을 헤더, 페이로드, 서명으로 풀어 보여 줍니다. exp, iat, nbf를 날짜로 바꾸고 만료 여부를 표시하며, HS256 서명을 검증합니다. 페이로드에 HMAC-SHA256으로 서명할 수도 있습니다
- URL: 퍼센트 인코딩과 디코딩
- 타임스탬프: Unix 초나 밀리초를 UTC와 현지 시각으로, 날짜나 "now"를 다시 타임스탬프로 바꿉니다
- 해시: SHA-1, SHA-256, SHA-384, SHA-512를 한 번에
- UUID: v4 UUID를 하나, 또는 한 번에 최대 100개까지
- 색상: HEX, RGB, HSL 중 무엇을 넣어도 세 형식을 모두 보여 줍니다
- 비교: 두 텍스트를 git diff처럼 줄 단위로 맞춰 비교하고 요약을 붙입니다

빠르게 쓰도록
- Ctrl+Enter로 실행, Ctrl+Shift+C로 결과 복사, Alt+1부터 Alt+9로 도구 전환
- 팝업에 넣기 큰 입력은 넓은 탭에서 열어 다룹니다
- 결과를 입력으로 넘겨 다음 도구에 이어서 넣습니다. 예를 들어 Base64를 디코딩한 결과를 그대로 JSON으로 정리할 수 있습니다
- 마지막에 쓴 도구, 모드, 옵션으로 다시 열립니다
- 도구마다 최근 입력 다섯 개를 기억합니다. 다시 열면 마지막 입력이 돌아오고, 나머지도 목록에서 골라 불러올 수 있습니다
- 밝은 테마와 어두운 테마. 따로 고르지 않으면 시스템 설정을 따릅니다
- 브라우저 언어에 맞춰 영어와 한국어로 표시

개인정보
- 권한 없음, 네트워크 요청 없음, 분석 도구 없음, 서버 없음
- 최근 입력, 테마, 마지막에 쓴 도구만 이 브라우저의 팝업 로컬 저장소에 보관합니다
